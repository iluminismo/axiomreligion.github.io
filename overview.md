# AXIOM Religion — Overview

## Description & Goal
Minimalist, high-editorial static website for **AXIOM**, a religion grounded in self-evident truth, praxeology, and the stewardship of reality. Built for GitHub Pages (`axiomreligion.github.io`) with luxury print-magazine visuals (*Kinfolk* / *Cereal* aesthetic), strong technical SEO, and functional, modular vanilla ES modules.
